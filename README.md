# CET-4 离线真题 + 听力音频

英语四级（CET-4）历年真题离线包，共 **46 套**，含听力音频，可完全离线使用，无需联网、无需登录。

## 试卷 PDF（每套 3 份，都在 `pdfs/`）

| 文件 | 说明 |
| --- | --- |
| `<套名>_完整.pdf` | **推荐**：一个文件恰好 2 页 —— 第 1 页原卷、第 2 页听力原文，两页各自是连续不断的「长长一条」，不是 A4 分页 |
| `<套名>_原卷.pdf` | 单独的原卷，恰好 1 页超长页面（写作 / 听力 / 阅读 / 翻译） |
| `<套名>_听力原文.pdf` | 单独的听力原文，恰好 1 页超长页面（新闻 / 长对话 / 篇章） |

页面高度按内容精确测量生成，所以每份都是**一整页连续内容，不会被切成二十几页 A4**，也没有分页留下的空白。

## 其他内容

- `index.html` — 总目录，列出全部 46 套，点击进入任意一套
- `papers/<年-月-套次>/`
  - `index.html` — 单套试卷网页版（可播放本地音频、有作答框）
  - `audio/SectionA.mp3`、`SectionB.mp3`、`SectionC.mp3` — 三段听力音频
  - `data.json` — 解密后的完整结构化内容
- `pdf_src/` — 生成 PDF 用的中间 HTML（每套「原卷.html」「听力原文.html」）
- `render.mjs` — 网页版 / 打印版共用的渲染模块
- `build.mjs` — 从站点抓取试卷与音频（联网）
- `rebuild.mjs` — 从本地 `data.json` 重建所有 HTML 与 PDF（不联网）

## 内容还原说明

- 阅读理解三种题型均已完整还原：选词填空（含词库与空格）、段落匹配（段落 A–K + 待匹配句子）、仔细阅读（完整文章 + 题目选项）。
- 听力原文自动兼容站点的两套字段命名，并把 SRT 字幕里的序号、时间码清理掉，还原成可读的连续原文（部分卷子为中英对照）。
- 离线包不含标准答案与解析（需登录原站查看）。

## 使用

直接双击 `index.html`（或 `papers/<某套>/index.html`）即可在浏览器离线刷题、听听力；打印/存档用 `pdfs/<套名>_完整.pdf`。

## 重新生成（可选）

```bash
npm install puppeteer-core pdf-lib
node rebuild.mjs          # 需要本机有 Edge 或 Chrome
```
