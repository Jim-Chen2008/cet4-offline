# CET-4 离线真题 + 听力音频

英语四级（CET-4）历年真题离线包，共 **46 套**，含听力音频，可完全离线使用，无需联网、无需登录。

## 内容

- `index.html` — 总目录，列出全部 46 套，点击进入任意一套
- `papers/<年-月-套次>/`
  - `index.html` — 单套试卷（听力题+选项、阅读、写作、翻译、听力原文），音频用相对路径引用本地 MP3
  - `audio/SectionA.mp3`、`SectionB.mp3`、`SectionC.mp3` — 三段听力音频（本地文件）
  - `data.json` — 解密后的完整结构化内容（备查）
- `pdfs/` — 46 套试卷的 PDF 版本
- `pdf_src/` — 由 `data.json` 生成 PDF 的源文件
- `build.mjs` / `make_pdfs.mjs` — 抓取与生成脚本

## 使用

直接双击 `index.html`（或 `papers/<某套>/index.html`）即可在浏览器离线刷题、听听力。

- 真题与听力音频版权归原题命题方 / 来源平台所有，本仓库仅作**个人离线备份与学习使用**，请勿公开二次分发。
- 离线包不含标准答案与解析（需登录原站查看）。
